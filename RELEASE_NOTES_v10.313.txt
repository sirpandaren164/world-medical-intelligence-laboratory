MIW v10.313 — Clinical Booklet / METASTAT Source Truth / TOC Segments

Primary targets
1) METASTAT source-truth interpretation
- Primary destination is shown only when explicitly reported in the RGCC conclusion.
- Other organ findings are shown only when their marker is explicitly reported as UP REGULATED.
- Removed comparator-derived organ ranking and probability-like ordering.
- No Sample-vs-Normal heuristic is used to invent metastatic risk.

2) TOC non-contiguous page ranges
- TOC entries now preserve true page segments.
- Example: Gene expression can display 72–75, 137–217 instead of the misleading 72–217 when Natural Substances / Additional Drug pages sit between those segments.

3) Clinical Booklet vs Full Technical Report
- New default: Clinical Booklet.
- Onconomics keeps all source results in compact complete tables instead of expanding every row into a dedicated explanation page.
- OncoTrail/METASTAT use compact detail tables.
- Masuyama keeps the guide/hexagon + overall history in Clinical Booklet; parameter-by-parameter technical pages remain in Full Technical Report.
- Specific IgE and Food-specific IgG use denser clinical tables to control page count while preserving source values.
- Full Technical Report remains available for full graphs and item-level explanations.

Clinical Booklet is designed to bring very large multi-module booklets toward a practical reading length; exact page count depends on the number and type of imported results.
