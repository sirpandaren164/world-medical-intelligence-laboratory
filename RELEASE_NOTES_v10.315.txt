MIW v10.315 — FoodPrint Source Truth Guard

Purpose
- Protect Food-specific IgG names and values from column/row drift in the 2-page FoodPrint 200+ layout.
- Full Report remains the default export; Clinical Summary remains optional.

What changed
1. Stable FoodPrint page ordinal
   - FoodPrint page 1/2 is now assigned independently of the physical page number inside a merged PDF.
   - A FoodPrint report on merged PDF pages 11-12 is still mapped internally as FoodPrint P1/P2.

2. Verified 222-item source-truth catalog
   - Added a complete position catalog: P1/C1=36, P1/C2=36, P1/C3=35, P2/C1=39, P2/C2=39, P2/C3=37; total 222.
   - When the source grid shape matches, food names are taken from the verified source-position catalog, while numeric values remain source-row values from the PDF.
   - Prevents OCR artifacts such as "I นมวัว", "อฮ้อย", and corrupted "แห้วไทย" from reaching reports.

3. Exact completeness guard
   - FoodPrint 200+ must resolve to exactly 222 unique position rows.
   - Name rows must be catalog-verified; OCR fallback rows remain review issues instead of silently passing.

4. Legacy database repair
   - Existing v10.314 FoodPrint rows are repaired during Patient Booklet load by mapping old physical-page keys (for example P11/P12) back to FoodPrint page ordinals P1/P2.
   - Corrected canonical names are persisted back to laboratoryResults when row IDs are available.
   - No re-upload is required when the existing rows retain foodIntoleranceItemKey.

5. Same canonical rows for both exports
   - Full Report and Clinical Summary use the same repaired FoodPrint rows.
   - FoodPrint overview shows the Source Truth Guard verification count when available.

Unchanged
