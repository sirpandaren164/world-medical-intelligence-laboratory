MIW v10.316 — FoodPrint Provenance Guard

Purpose
- Add source-page provenance verification on top of the v10.315 FoodPrint Source Truth Guard.
- A FoodPrint row is no longer considered fully protected only because its food name matches the 222-item catalog; its P/C/R position and source PDF page must also resolve consistently.

What changed
1. Provenance metadata at parse time
   - Every catalog-verified FoodPrint row records canonical P1/P2, column, row, canonical position key, and the physical source PDF page.
   - New metadata fields include foodPrintProvenanceStatus, foodPrintProvenancePositionKey, foodPrintProvenanceSourcePage, page ordinal, column and row.

2. Legacy provenance repair
   - Patient Booklet groups FoodPrint rows by source document/date and resolves the dominant physical source page for FoodPrint P1 and P2.
   - Legacy rows that carry the correct canonical position but point to the wrong source page are repaired before rendering and persisted back to laboratoryResults.
   - Original page metadata is retained in provenance audit fields when a repair occurs.

3. Structural export gate
   - FoodPrint Source Truth Guard and FoodPrint Provenance Guard are both blocking guards.
   - Export is stopped if any FoodPrint row cannot resolve both its canonical name/position and source page provenance.

4. Booklet visibility
   - FoodPrint overview now shows two independent checks:
     • FoodPrint Source Truth Guard: verified food names.
     • FoodPrint Provenance Guard: verified P/C/R + source page.
   - If legacy provenance was repaired, the booklet reports the number of repaired rows.

Regression target from supplied Somchai FoodPrint source
- FoodPrint source page 1 corresponds to merged source PDF page 11.
- FoodPrint source page 2 corresponds to merged source PDF page 12.
- P1-C1-R30 รำข้าวสาลี = 15 U/mL must cite merged PDF page 11, not page 12.
- P1-C1-R29 นกกระจอกเทศ = 15 U/mL must cite page 11.
- P1-C1-R28 แฟง (ผักในตระกูลน้ำเต้า) = 15 U/mL must cite page 11.
- P1-C1-R12 แห้วไทย = 22 U/mL must cite page 11.
- P2 rows must cite page 12.

Unchanged
- Onconomics parser/source-truth
- OncoTrail / METASTAT source-truth behavior
- Additional drug source-fidelity logic
- Full Report remains default; Clinical Summary remains optional
